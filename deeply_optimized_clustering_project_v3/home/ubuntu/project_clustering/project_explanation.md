## 2. 数据预处理与探索性数据分析 (EDA) 优化 (`step0_eda_preprocessing_v2.ipynb`)

### 2.1 目的与意义

数据预处理是任何机器学习项目的基础。此阶段的目标是清洗、转换原始数据，使其适合聚类算法。优化后的 `step0_eda_preprocessing_v2.ipynb` 不仅完成了这些基本任务，更重要的是，它通过引入有意义的可视化和混淆矩阵，深化了对数据内在结构的理解，为后续的聚类分析提供了更坚实的业务背景。

### 2.2 关键优化点

#### 2.2.1 有意义的 EDA 可视化

**性别与消费分数分布 (Spending Score Distribution by Gender)**：通过箱线图（Box Plot）比较不同性别的消费分数分布（中位数、四分位数、异常值），我们可以直观地了解男性和女性客户在购物中心内的消费意愿和能力是否存在显著差异。例如，如果男性客户的消费分数中位数明显高于女性，商场可以考虑针对男性客户推出更高价值的商品或服务，或者分析女性客户消费潜力未被充分挖掘的原因。

**收入与消费分数散点图 (Annual Income vs Spending Score)**：此散点图（Scatter Plot），并按性别着色，旨在揭示客户的年收入与消费分数之间的关系。这是客户细分最核心的两个特征。通过观察散点图中是否存在明显的客户群体聚集（例如：高收入高消费、低收入低消费、高收入低消费等），可以初步判断数据是否具有良好的聚类结构。如果能看到清晰的簇，则表明聚类算法有望成功识别出不同的客户细分群体，为精准营销提供依据。

#### 2.2.2 混淆矩阵 (Confusion Matrix) 分析

老师建议在预处理阶段引入混淆矩阵。虽然聚类是无监督学习，没有“真实标签”来计算传统意义上的混淆矩阵，但在 EDA 阶段，我们可以通过将连续特征（如 `Spending Score`）进行分桶（例如分为“高消费”和“低消费”），然后观察它与另一个分类特征（如 `Gender`）之间的交叉分布。此热力图（Heatmap）形式的混淆矩阵展示了性别与消费水平（分桶后）的关联性。例如，矩阵中“女性”行与“低消费”列的交叉格数值较大，可能意味着大部分女性客户属于低消费群体。这有助于我们理解特征之间的潜在关系，并为后续聚类结果的解释提供业务洞察。它能帮助我们回答“特定性别是否倾向于某种消费行为”的问题，从而为商场的营销策略提供数据支持。

#### 2.2.3 特征缩放与数据保存

此步骤将数值特征标准化（StandardScaler），确保所有特征在相同的尺度上，避免某些特征因数值范围较大而在聚类过程中占据主导地位。标准化后的数据 `X_scaled.npy` 和 `data_preprocessed.csv` 将被保存，供所有聚类算法 Notebook 使用，确保数据一致性。

## 3. K-Means 聚类优化 (`member1_kmeans_v2.ipynb`)

### 3.1 目的与意义

K-Means 是一种经典的基于距离的聚类算法。优化后的 `member1_kmeans_v2.ipynb` 解决了原始 K-Means 笔记本中肘部法则可视化不清晰和聚类结果 2D 展示重叠的问题，并引入了 V-measure 评估，使结果更具说服力。

### 3.2 关键优化点

#### 3.2.1 改进的肘部法则 (Elbow Method) 可视化

我们使用 `yellowbrick` 库的 `KElbowVisualizer` 来改进肘部法则的可视化。`KElbowVisualizer` 能够自动识别并标注“肘部”位置，使得最佳聚类数 K 的选择更加直观和客观。在业务中，选择合适的 K 值至关重要，因为它直接决定了客户细分的粒度。一个清晰的肘部图能帮助决策者理解为什么选择某个 K 值，从而避免主观臆断。

#### 3.2.2 V-measure 评估

老师建议引入 V-measure。V-measure 是一种外部聚类评估指标，用于衡量聚类结果与“真实标签”（如果存在的话，例如本例中的 `Gender` 可以作为参考）的一致性。它结合了同质性（Homogeneity，每个簇只包含单一类别的样本）和完整性（Completeness，同一类别的所有样本都分到同一个簇）。V-measure 越接近 1，表示聚类结果与参考标签（如性别）的匹配度越高。这有助于我们理解聚类算法在多大程度上能够“发现”数据中已知的结构。如果 V-measure 较低，则说明性别可能不是驱动客户细分的主要因素，而其他特征（如收入、消费分数）可能更重要，这为业务策略提供了新的思考方向。

#### 3.2.3 3D 聚类可视化

原始的 2D PCA 聚类图经常出现簇重叠，难以区分。通过基于 `Age`、`Annual Income` 和 `Spending Score` 的 3D 散点图，我们可以将客户点投射到三维空间中，更清晰地观察不同簇之间的空间分布和边界。这对于理解客户群体的真实分离情况至关重要，尤其是在数据维度较高时。例如，在 3D 视图中，原本在 2D 投影下看似重叠的两个客户群体，可能在第三个维度上呈现出明显的分离，从而揭示出更精细的客户细分模式。

## 4. DBSCAN 聚类优化 (`member3_dbscan_v2.ipynb`)

### 4.1 目的与意义

DBSCAN 是一种基于密度的聚类算法，它能够发现任意形状的簇，并且可以识别噪声点。优化后的 `member3_dbscan_v2.ipynb` 引入了 3D 聚类可视化和 V-measure 评估，以更好地展示 DBSCAN 的特性和评估其效果。

### 4.2 关键优化点

#### 4.2.1 3D 聚类可视化

与 K-Means 类似，DBSCAN 的 2D 投影也可能导致簇重叠。通过基于 `Age`、`Annual Income` 和 `Spending Score` 的 3D 散点图，并区分噪声点，能够更清晰地展示 DBSCAN 如何根据数据点的密度来形成簇，并突出显示被识别为“噪声”的异常客户。在客户细分中，识别噪声点（如异常消费行为的客户）对于风险管理或特殊营销策略具有重要意义。3D 视图能帮助我们直观理解哪些客户是核心群体，哪些是边缘或异常。

#### 4.2.2 V-measure 评估

同样，使用 V-measure 评估 DBSCAN 聚类结果与性别标签的一致性。DBSCAN 的 V-measure 结果可以帮助我们判断，基于密度的聚类方法在多大程度上能够捕捉到与性别相关的客户群体。如果 DBSCAN 能够发现与性别高度相关的密度区域，V-measure 将会较高。这有助于比较不同聚类算法在发现已知结构方面的表现。

## 5. 深度学习聚类 (Autoencoder + K-Means) (`member4_deeplearning_v2.ipynb`)

### 5.1 目的与意义

为了响应老师关于引入深度学习算法的建议，我们新增了基于自动编码器（Autoencoder）和 K-Means 的聚类方法。这种方法利用自动编码器进行非线性降维和特征学习，然后在学习到的低维潜在空间中应用 K-Means 聚类。这对于处理复杂、高维数据，并发现传统方法难以捕捉的非线性结构尤其有效。

### 5.2 关键优化点

#### 5.2.1 自动编码器 (Autoencoder) 模型构建与训练

我们构建了一个包含编码器（Encoder）和解码器（Decoder）的简单全连接神经网络。编码器将原始输入数据压缩到一个低维的“潜在空间”（Latent Space），解码器则尝试从潜在空间重建原始数据。通过使用 `epochs` 参数进行模型训练，自动编码器会不断优化其权重，学习如何更有效地从原始数据中提取最重要的特征，并将其表示在潜在空间中。训练过程中会展示损失（Loss）的变化曲线，通常期望损失随 Epoch 增加而下降，表明模型正在学习。自动编码器能够学习数据中更抽象、非线性的特征表示。这意味着它可能发现传统线性降维方法（如 PCA）无法捕捉的客户行为模式。在潜在空间中进行聚类，有望得到更具区分度和业务价值的客户细分。损失曲线的下降表明模型学习效果良好，提取的特征更具代表性。

#### 5.2.2 潜在空间特征提取与 K-Means 聚类

训练完成后，我们只使用自动编码器的编码器部分，将原始标准化数据 `X_scaled` 映射到低维的潜在空间 `X_encoded`。这个 `X_encoded` 就是深度学习学习到的新特征表示。随后，在 `X_encoded` 上应用 K-Means 算法进行聚类。由于潜在空间中的特征是经过非线性学习的，它们可能更好地分离不同的客户群体。同时，使用 V-measure 评估深度学习聚类结果与性别标签的一致性，这有助于比较深度学习方法与传统方法在发现已知结构方面的性能。

#### 5.2.3 潜在空间 3D 聚类可视化

此图展示了在深度学习学习到的特征空间中，客户是如何被聚类的。通过基于自动编码器潜在空间中的三个维度（`Latent Feature 1`, `Latent Feature 2`, `Latent Feature 3`）的 3D 散点图，与原始特征空间或 PCA 空间相比，潜在空间中的簇可能更加紧密和分离，这表明自动编码器成功地将相似的客户拉近，将不相似的客户推远。这种更清晰的区分有助于商场制定更精准、更有效的营销策略，因为客户群体之间的界限更加明确。
